# Matematyka w praktyce
type: Wiedza

Część [[Nauka i technika]]. Skrót użytecznych narzędzi do zadań (poziom egzaminu ósmoklasisty i matury podstawowej, także zastosowania w technice). Zastosowania w [[Fizyka podstawowa]] i [[Elektronika i mikrokontrolery]].

## Algebra i równania

- Kolejność działań: nawiasy, potęgi i pierwiastki, mnożenie i dzielenie, dodawanie i odejmowanie.
- Wzory skróconego mnożenia: (a+b)² = a² + 2ab + b², (a-b)² = a² - 2ab + b², a² - b² = (a-b)(a+b).
- Równanie liniowe ax + b = 0 daje x = -b/a (dla a różnego od 0). Co robisz po jednej stronie, rób po drugiej.
- Nierówność: mnożenie lub dzielenie przez liczbę ujemną odwraca znak nierówności.
- Procenty: p% z x to x · p/100. Wzrost o p%: pomnóż przez (1 + p/100). Spadek o p%: przez (1 - p/100). Zmiana o 10% w górę, a potem o 10% w dół, nie wraca do wyniku (daje 0,99).
- Potęgi: a^m · a^n = a^(m+n), a^m / a^n = a^(m-n), (a^m)^n = a^(m·n), a^0 = 1, a^(-n) = 1/a^n.
- Proporcje: a/b = c/d daje a·d = b·c.

## Układy równań

- Metoda podstawiania: wyznacz jedną niewiadomą z jednego równania i wstaw do drugiego.
- Metoda przeciwnych współczynników: pomnóż równania tak, by dodanie ich wyeliminowało jedną niewiadomą.
- Przykład: x + y = 5 i x - y = 1. Dodaj: 2x = 6, czyli x = 3, y = 2. Zawsze sprawdź wynik w obu równaniach.
- Układ może mieć jedno rozwiązanie, żadnego (proste równoległe) lub nieskończenie wiele (ta sama prosta).

## Funkcje

- Funkcja liniowa y = ax + b: a to nachylenie (współczynnik kierunkowy), b to wartość dla x = 0. Miejsce zerowe x = -b/a. Rośnie dla a > 0, maleje dla a < 0.
- Prosta przez dwa punkty (x1,y1), (x2,y2): a = (y2 - y1)/(x2 - x1).
- Funkcja kwadratowa y = ax² + bx + c: parabola. Delta Δ = b² - 4ac. Dla Δ > 0 dwa pierwiastki x = (-b ± √Δ) / (2a), dla Δ = 0 jeden x = -b/(2a), dla Δ < 0 brak miejsc zerowych. Wierzchołek ma x_w = -b/(2a). Ramiona w górę dla a > 0, w dół dla a < 0.
- Funkcja wykładnicza y = a^x i logarytm to jej odwrotność: log_a(b) = c oznacza a^c = b.
- Odczytywanie wykresów: dziedzina to dozwolone x, zbiór wartości to osiągane y.

## Pochodne po ludzku

- Pochodna mówi, jak szybko funkcja się zmienia w danym punkcie: nachylenie stycznej do wykresu, "prędkość" zmiany. Jeśli s(t) to droga, to s'(t) to prędkość.
- Podstawowe wzory: (c)' = 0, (x^n)' = n · x^(n-1), (sin x)' = cos x, (cos x)' = -sin x, (e^x)' = e^x, (ln x)' = 1/x.
- Reguły: (f+g)' = f' + g', (c·f)' = c·f', (f·g)' = f'g + fg', funkcja złożona (f(g(x)))' = f'(g(x)) · g'(x).
- Ekstremum (najmniejszy lub największy wynik): znajdź punkty, gdzie f'(x) = 0, i sprawdź zmianę znaku pochodnej (z plus na minus to maksimum, z minus na plus to minimum). To standardowe zadanie "optymalizacji", np. jakie wymiary dają największe pole.
- Pochodne nie są wymagane na maturze podstawowej, a na rozszerzonej tak.

## Geometria

- Pole: prostokąt a·b, trójkąt a·h/2, trapez (a+b)·h/2, równoległobok a·h, koło πr². Obwód koła 2πr.
- Twierdzenie Pitagorasa: a² + b² = c² dla trójkąta prostokątnego (c to przeciwprostokątna). Trójka 3-4-5 to prosty przykład.
- Objętość: prostopadłościan a·b·c, walec πr²h, stożek (1/3)πr²h, kula (4/3)πr³. Pole powierzchni kuli 4πr².
- Suma kątów trójkąta wynosi 180 stopni. Kąty przyległe sumują się do 180, wierzchołkowe są równe.
- Podobieństwo figur o skali k: długości razy k, pola razy k², objętości razy k³.
- Twierdzenie Talesa: proste równoległe odcinają proporcjonalne odcinki na ramionach kąta.

## Trygonometria

- W trójkącie prostokątnym: sin α = przyprostokątna przeciwległa / przeciwprostokątna, cos α = przyprostokątna przyległa / przeciwprostokątna, tg α = przeciwległa / przyległa.
- Wartości do zapamiętania: sin 30° = 1/2, sin 45° = √2/2, sin 60° = √3/2. Cosinus odwrotnie: cos 30° = √3/2, cos 60° = 1/2. tg 45° = 1.
- Jedynka trygonometryczna: sin² α + cos² α = 1. Zależność tg α = sin α / cos α.
- Przeliczenie: 180° = π radianów. Kalkulator musi mieć właściwy tryb (stopnie lub radiany). To najczęstszy błąd.

## Prawdopodobieństwo i statystyka

- Prawdopodobieństwo zdarzenia = liczba zdarzeń sprzyjających / liczba wszystkich (przy równych szansach). Zawsze między 0 a 1.
- Zdarzenia niezależne: P(A i B) = P(A) · P(B). Przeciwne zdarzenie: P(nie A) = 1 - P(A).
- Średnia arytmetyczna to suma / liczba. Mediana to środkowa wartość po uporządkowaniu. Dominanta to najczęstsza.
- Kombinatoryka: permutacje n! , kombinacje C(n,k) = n! / (k!(n-k)!).

## Jak rozwiązywać zadania tekstowe

1. Przeczytaj dwa razy, wypisz dane i szukane z jednostkami.
2. Wprowadź oznaczenia (x to szukana wielkość) i ułóż równanie.
3. Rozwiąż, sprawdź sens wyniku (czy ujemna liczba osób ma sens) i odpowiedz zdaniem.
4. Pilnuj jednostek: przelicz minuty na godziny, cm na m przed podstawieniem do wzoru.

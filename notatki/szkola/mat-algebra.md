# Algebra i równania
type: Nauka

Część [[Matematyka]].

## Wyrażenia algebraiczne

- Redukcja wyrazów podobnych: 3x + 2x = 5x. Wyłączanie przed nawias:
  ax + ay = a(x+y).

## Wzory skróconego mnożenia

- (a+b)² = a² + 2ab + b²
- (a−b)² = a² − 2ab + b²
- (a−b)(a+b) = a² − b² (różnica kwadratów)

## Równania liniowe

- ax + b = 0 → x = −b/a (dla a≠0). Zasada: to samo rób po obu stronach.

## Równanie kwadratowe

- ax² + bx + c = 0. Delta: Δ = b² − 4ac.
- Δ>0: dwa pierwiastki x = (−b ± √Δ)/(2a). Δ=0: jeden x = −b/(2a). Δ<0:
  brak pierwiastków rzeczywistych.

## Nierówności

- Jak równania, ale mnożąc/dzieląc przez liczbę ujemną ODWRACAJ znak.

## Układy równań

- Metoda podstawiania (wyznacz jedną zmienną i wstaw) albo przeciwnych
  współczynników (dodaj równania tak, by jedna zmienna zniknęła).

# Prawdopodobieństwo i statystyka
type: Nauka

Część [[Matematyka]].

## Prawdopodobieństwo

- P(A) = liczba zdarzeń sprzyjających / liczba wszystkich zdarzeń
  (dla zdarzeń jednakowo możliwych). Zawsze 0 ≤ P ≤ 1.
- Przykład: rzut kostką, P(parzysta) = 3/6 = 1/2.
- Zdarzenie pewne P=1, niemożliwe P=0. P(nie A) = 1 − P(A).

## Kombinatoryka (zliczanie)

- Reguła mnożenia: jeśli jeden wybór ma m możliwości, a drugi n, to razem
  m·n. Silnia: n! = 1·2·…·n (liczba ustawień n elementów).

## Statystyka

- Średnia arytmetyczna: suma / liczba elementów.
- Mediana: wartość środkowa po uporządkowaniu (dla parzystej liczby -
  średnia dwóch środkowych).
- Dominanta (moda): wartość występująca najczęściej.
- Rozstęp: największa − najmniejsza wartość.
